# なまえの森

タブレット1台を囲んで遊ぶ、2〜6人向けの名前記憶ゲーム。独自キャラクター12種類。

## 遊ぶ

https://learning-apps-jp.github.io/name-forest/

初めての絵には名前を付けて文字入力します。同じ絵が再登場したら声で名前を呼び、参加者で最初の正解者を決めて得点を登録します。音声認識は使用していません。

30枚／60枚、名前の訂正、直前操作の取り消し、中断再開に対応。進行は同じ端末・ブラウザー内に保存します。初回の必要ファイル取得後はオフラインでプレイできます。

Safari／Chromeからホーム画面に追加できます。実機のiPad・Androidでの最終確認は未実施です。

## 開発

外部ライブラリー不要。静的ファイルをHTTPサーバーで配信するか、index.htmlをブラウザーで開いてください。PWAにはHTTPSまたはlocalhostが必要です。

このアプリはナンジャモンジャの基本的な遊び方を参考にした独自イラストのゲームです。公式の商品画像・ロゴは使用していません。
